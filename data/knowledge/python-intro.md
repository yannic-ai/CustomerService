# Python入门课

课程名称：Python入门课
适合人群：零基础学员
总时长：24 小时
前置要求：会使用电脑；无需编程基础

## 课程简介

Python入门课帮助学员从零搭建开发环境，掌握语法、流程控制、数据结构、函数与模块，并在课程末尾完成命令行待办工具实战。

## 模块1：环境搭建与基础语法

- 安装 Python 解释器与 VS Code / PyCharm
- 变量、数字、字符串与布尔类型
- 输入输出、运算符、注释规范
- 学习目标：能独立运行第一段 Python 程序
- 建议时长：4 小时

## 模块2：流程控制

- if / elif / else 条件判断
- for 与 while 循环
- break、continue 与简单算法题
- 学习目标：能编写分支与循环逻辑
- 建议时长：4 小时

## 模块3：数据结构

- 列表、元组、字典、集合
- 切片、推导式与常用方法
- 学习目标：能选择合适的数据结构解决问题
- 建议时长：5 小时

## 模块4：函数与模块

- 函数定义、参数、返回值与作用域
- 模块导入、包结构、虚拟环境
- 学习目标：能拆分可复用函数并组织项目结构
- 建议时长：4 小时

## 模块5：文件、异常与面向对象

- 文本文件读写
- try / except 异常处理
- 类、对象、封装与继承
- 学习目标：能读写文件并用类建模简单业务
- 建议时长：4 小时

## 模块6：综合实战：命令行待办工具

- 需求拆解与功能列表
- 本地文件持久化
- 命令解析、测试与发布
- 学习目标：完成一个可运行的命令行小项目
- 建议时长：3 小时

## 学习路径

1. 入门阶段：模块1 + 模块2，先跑通环境并写对控制流
2. 巩固阶段：模块3 + 模块4，用数据结构和函数组织代码
3. 实战阶段：模块5 + 模块6，结合文件、异常与面向对象完成项目
