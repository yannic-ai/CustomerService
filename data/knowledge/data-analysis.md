# 数据分析实战

课程名称：数据分析实战
适合人群：已掌握 Python 基础的学员
总时长：20 小时
前置要求：完成 Python入门课或同等基础

## 课程简介

基于 Python 完成业务数据分析：NumPy 计算、Pandas 清洗与聚合，以及可视化报告。

## 模块1：NumPy 基础

- ndarray、广播、统计运算
- 学习目标：掌握数组计算
- 建议时长：4 小时

## 模块2：Pandas 数据处理

- DataFrame、缺失值、分组聚合
- 学习目标：能完成常规数据清洗
- 建议时长：8 小时

## 模块3：可视化与报告

- matplotlib、seaborn、业务洞察
- 学习目标：输出分析报告
- 建议时长：8 小时

## 学习路径

1. 入门阶段：模块1
2. 巩固阶段：模块2
3. 实战阶段：模块3
