# 机器学习基础

课程名称：机器学习基础
适合人群：具备 Python 与数据分析基础的学员
总时长：28 小时
前置要求：完成数据分析实战或同等基础

## 课程简介

监督学习入门，覆盖特征工程、经典模型和模型评估，帮助学员建立可落地的 ML 工作流。

## 模块1：机器学习导论

- 任务类型、训练集、过拟合
- 学习目标：建立 ML 基本概念
- 建议时长：4 小时

## 模块2：特征工程

- 缺失值、编码、标准化
- 学习目标：能准备训练数据
- 建议时长：6 小时

## 模块3：经典模型

- 线性回归、逻辑回归、决策树、随机森林
- 学习目标：能训练并比较模型
- 建议时长：12 小时

## 模块4：评估与调参

- 交叉验证、指标选择、网格搜索
- 学习目标：能评估并优化模型
- 建议时长：6 小时

## 学习路径

1. 入门阶段：模块1 + 模块2
2. 巩固阶段：模块3
3. 实战阶段：模块4
